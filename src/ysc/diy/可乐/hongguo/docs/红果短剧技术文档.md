> 维护对象：`hongguo/hongguo-spider.jar`（`src/com/github/catvod/spider/Hongguo.java`）
> 最后验证：2026-10-23（搜索/详情/播放全链路可用）
> 参考蓝本：N3urda/hongguoTV（drpys 衍生）、tsukiyo-zero/hongguoTV（2026-10 修复版，本地克隆于 `E:\HelloWorld\project\guoju\case\hongguoTV-tsukiyo`）

## 1. 总体架构

红果短剧数据分两个体系，jar 内全部覆盖：

| 体系 | 域名 | 用途 | 鉴权 |
|---|---|---|---|
| 官网 Web（SSR/CSR） | `hongguoduanju.com` | 首页/分类/详情/热搜榜（SSR `_ROUTER_DATA`）、搜索（纯 JSON API） | 无需签名，浏览器 UA 即可 |
| 幕后 App API | `api5-normal-sinfonlineb.fqnovel.com` 等 | 取流（播放地址 + 解密密钥） | 当前 `multi_video_model/v1` **免签名**（UA 关键）；其余端点需字节跳动签名家族 |
| 设备/账号体系 | `log5-applog-lf.fqnovel.com` | 设备注册（内容接口按设备放行的根源） | 匿名，不带签名头 |

jar 模块结构（Hongguo.java 单文件）：
- Web 抓取解析：`homeContent` / `categoryContent`（SSR `_ROUTER_DATA`）、`searchContent`（JSON API）、`detailContent`（SSR）
- 取流：`stream(vid)` → 壳侧本地代理 `/proxy` 分段回吐 + CENC 解密
- 解密：`decryptUrl`（播放地址信封解密）、`deriveKey`（spade_a → AES-128 CENC 密钥）
- MP4/CENC：`prepare` / `decrypt`（与蓝本 MediaCrypto 同构）

## 2. API 清单

### 2.1 搜索（2026-10 起官网搜索页改纯 CSR，SSR 解析失效，改走前端同款 JSON 接口）

```
GET https://hongguoduanju.com/api/search/result?aid=8662&query=<URLEncode>&pageNum=<页码，首页可省>
UA: 任意（浏览器 UA 最稳）
```

响应（JSON）：
```json
{
  "searchList": [ { "video_data": { "series_id", "series_title", "series_cover",
      "series_intro", "episode_cnt", "category_list": [{"name":...}] } } ],
  "totalCount": 123, "pageNum": 1, "totalPages": 13, "hasMore": true
}
```

要点：
- **无需 msToken / a_bogus 签名**，0.2~1s 返回；与分类页卡片同构（`video_data` 可直接走同一 `cards()` 解析）。
- 频控：连续高频请求返回 `{"code":"upstream_unavailable","message":"Search is temporarily unavailable."}`（HTTP >= 400）。jar 侧已做 600ms 退避重试一次。
- 官网搜索是**模糊匹配**：部分剧名（如《我在长征路上开超市》）官网搜库不召回，属官网行为非 bug。

### 2.2 首页/分类/详情（SSR）

```
GET https://hongguoduanju.com/category?tab=1&sort_type=1[&page=N]
GET https://hongguoduanju.com/page?series_id=<id>
GET https://hongguoduanju.com/rank/<route>[?page=N]     # hot-drama 等
UA: 浏览器 UA
```

解析：页面内嵌 `_ROUTER_DATA` 全局 JSON（`loaderData` 下按路由 key 取数据）。jar 的 `extractRouter` 用括号配对提取（容忍转义）。
**失效特征**：页面变纯 CSR（React `div#root`，无 `_ROUTER_DATA`）→ 搜索页 2026-10 已发生（故改 JSON API），其余页面仍 SSR。

### 2.3 热播榜（壳侧 HongguoRank，非 jar）

`GET /rank/hot-drama?page=N`，SSR 数据管道两种形态（2026-10-23 实测并存）：
- `data-fn-name="mergeLoaderData"`：args = `[route, [{key, routerDataFnName, routerDataFnArgs:[...]}]]`
- `data-fn-name="r"`（legacy）：args = `[route, "content", {isSuccess, rankList, pagination}]` ← **当前主力形态**
- **属性包裹引号双形态**：`data-fn-args="..."`（双引号，值内全 `&quot;`）与 `data-fn-args='...'`（单引号）。正则必须引号自适应：`(["'])(.+?)\1` + `Pattern.DOTALL`。固定单侧引号会全灭误入 DOM 兜底。
- 兜底：DOM 内容锚点解析（h2 剧名边界 + 热度文本模式），对服务端差异化响应免疫。回归样本：`app/src/test/resources/hongguo/real_squote.html`。

```
POST https://api5-normal-sinfonlineb.fqnovel.com/novel/player/multi_video_model/v1/?<query>
Content-Type / 请求头：见下
Body: {"biz_param":{"detail_page_version":0,"device_level":3,"disable_digg_stat":false,
        "need_all_video_definition":true,"need_mp4_align":false,"use_os_player":false,
        "use_server_dns":false,"video_platform":1024},
       "mixed_video_id_map":{"1004":["<vid>"]}}
```

### 2.5 设备注册（当前播放链路不需要，备用知识）

```
POST https://log5-applog-lf.fqnovel.com/service/2/device_register/?tt_data=a&cronet_version=8d40f833_2026-03-03&ttnet_version=4.2.243.31-douyin&use_store_region_cookie=1
Content-Type: application/octet-stream;tt-data=a
log-encode-type: gzip / x-ss-dp: 8662 / x-neptune: -8|50:51:59:30:40:47:49:39
x-ss-stub: <body MD5 大写>
Body: ttEncrypt(gzip(JSON))   ← 原始二进制，不是 base64 文本
```

- **刻意不带任何签名头**（x-gorgon 等带上反而被判异常客户端）。
- 响应：`{"device_id","install_id","device_token","new_user"}` + Set-Cookie（install_id/ttreq/store-region）。
- 三个坑：body 是原始二进制（发 base64 文本必回 device_id=0）；响应可能 brotli 压缩；`os_version` 必须是**字符串**。
- 何时需要：`/reading/bookapi/search/tab/v`（App 搜索）与账号接口按设备放行——未注册设备一律 200+0 字节或 `101000 服务异常`。我们搜索走官网、取流走 v1 免签名端点，故不需要。

### 2.6 字节跳动签名家族（当前未用，官方升级签名时需移植）

现役可用端点 `multi_video_model/v1` 免签名。**若服务端收紧**，需移植完整签名栈（tsukiyo `Signer.kt`，GPL-3.0，本地 case 目录有源码）：

| 头 | 算法要点 |
|---|---|
| x-gorgon（新版 0x4041 形态） | MD5(query)[0:4] + MD5(body)[0:4] + 4 零 + le32(67503104) + be32(ts) → RC4（key 含 2 字节随机）→ 字节扭转循环；前缀 `8404` + [rand.lo, rand.hi, 0x40, 0x01] |
| x-helios | XTEA 变体（34 轮表驱动），明文 `ts-1588093228-8662` PKCS7 |
| x-medusa | protobuf 组包（设备描述 deviceProto + 环境 + sm3(query+body+ts) 链）→ xmxor → AES(V3) → base64，依赖 sbox/hashTable 常量 |
| x-ladon / x-argus | tsukiyo 实测发 4 字节占位（be32/le32(ts) 的 base64）即可 |
| hash branch | `branch(query,body,ts)` 必须为 0（只实现 branch 0）：暴力微调 `_rticket`（0..127 offset）直至命中 |

旧版 legacyGorgon（0x401c，曾用于 preload）算法已从 jar 删除，历史见 git；其被软拒的根因见 §4。

## 3. 解密算法

### 3.1 播放地址解密 `decryptUrl(main_url_b64, key_seed)`

```
raw = Base64Decode(main_url)                      # 信封校验：raw[0]=0xa8, raw[2]=1, raw[3]=0
h   = SHA512( SHA512(key_seed_bytes) || SPADE_CONST_hex )
url = AES-128-CBC-Decrypt(key=h[0:16], iv=h[16:32], raw[4:])   # NoPadding，去 PKCS7 与尾部 \0
```
SPADE_CONST 为 jar 内固定 hex 常量（与蓝本 MediaCrypto 同源）。

### 3.2 CENC 内容密钥派生 `deriveKey(spade_a)`

```
raw = Base64Decode(spade_a)
len = min(raw.len - (raw[0]^raw[1]^raw[2]) + 47, raw.len - 1)    # 必须 >= 33
work = raw[1 : 1+len]，按位翻转链（奇偶交替 a/b 状态，-21 - bitCount(i) + prev^old）
key = hexOf( work[1:33] 的 ISO-8859-1 字符串 )                    # 16 字节 AES-128 CENC key
```

### 3.3 播放管道（壳侧配合）

jar 返回 `proxy://do=...` 形式地址 → 壳本地代理收到 Range 请求后：调 jar `proxyLocal` 拉取分片 → moov 头解析（tenc 拿 kid/iv）→ 用 §3.2 密钥做 AES-CTR(CENC) 逐样本解密 → 字节回吐。壳仅作数据转发管道不感知内容逻辑。

## 4. 风控行为实录（升级排查必读）

| 时间 | 事件 | 特征 | 应对 |
|---|---|---|---|
| 2026-10 上旬 | 官网搜索页改纯 CSR | SSR 解析抛 "router data missing" | 改走 `/api/search/result` JSON 接口 |
| 2026-10-23 | **取流 preload/v1 被软拒** | `HTTP 200 + 0 字节`（网关有 trace-id/Server-Timing，直接回空）；桌面 1:1 复现同样空体 → 全局拒绝非设备/IP 特异 | 换 `multi_video_model/v1` + 播放专用 UA + 稳定 3+18 位设备号 + 免签名头 |

**"200 空体" 是字节系网关的通用软拒特征**（内容接口按设备放行的表现）。排查顺序：
1. 先用桌面 PowerShell 1:1 复现（参数+UA+body 原样），确认全局/设备特异；
2. 对照 tsukiyo 仓库最近提交（`case/hongguoTV-tsukiyo`，git pull 更新）看端点/参数/UA 是否变更；
3. 若 v1 也开始空体 → 移植 §2.6 签名家族（对照 Signer.kt）或注册设备（§2.5）。

**其他失效特征**：搜索频控 `upstream_unavailable`；播放接口错误码 `101000`=设备未注册/服务异常；`Code!=0` 见响应体 message。

## 6. 流程速查

```
搜索:  关键词 → URLEncode → GET /api/search/result?aid=8662&query=..&pageNum=..
       → searchList[].video_data → cards() 去重过滤 → 列表
详情:  GET /page?series_id=.. → extractRouter(_ROUTER_DATA) → 集数 vids
播放:  vid → POST multi_video_model/v1 (UA 关键, 免签名)
       → data[vid].video_model.fallback_api → GET fallback
       → video_info.data: key_seed + video_list
       → 清晰度筛选(排除 bytevc2/bvc2, 取<=1080 最高档)
       → decryptUrl(main_url, key_seed) → deriveKey(spade_a)
       → proxy:// → 壳本地代理分段拉流 + AES-CTR CENC 解密 → 播放器
```
