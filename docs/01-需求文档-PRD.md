# 可乐 · 网盘资源聚合搜索 · 重构需求文档（PRD）

> 版本：v2.0 ｜ 日期：2026-10-13 ｜ 状态：待评审
>
> 分析主体：`demo/kelePro`（uni-app H5 + Cloudflare Workers + D1 的重构版）
> 决策：**删除 kelePro 项目，整合到 kele 项目中重建**（目标根目录 `e:\HelloWorld\project\kele`）

---

## 1. 背景

现状：`demo/kelePro` 是"可乐影视资源聚合搜索"的一次完整重构尝试，已实现：

- 前端 uni-app（Vue3 + TS）H5，13 个页面（首页/搜索/详情/收藏/在线影视/我的/登录/注册/VIP/管理后台）
- 后端 Cloudflare Workers + D1 数据库，7 组 API 路由，4 个爬虫源，4 个定时任务
- 完整数据层（资源/收藏/公告/热搜/豆瓣榜单/广告/日志等十余张表）

但存在核心痛点：

1. **接口极易失效**：搜索源是第三方个人 API / 爬虫网页，随时停服或改版。kelePro 虽有 `api_configs` 配置表，但解析器仍硬编码在代码里（`parsers.ts`），新增一个返回格式不同的源就要改代码、重新部署；没有健康监控、没有自动熔断、没有后台连通性测试。**源挂了 = 功能不可用**。
2. **小程序端未完成**：uni-app 配置了 mp-weixin 但 appid 是占位符，未处理小程序域名白名单（`*.workers.dev` 无法加入微信 request 合法域名）、未做小程序端交互适配。
3. **系统过重**：登录/注册/VIP 等级/广告系统在免费个人项目里维护成本高、审计风险大，与实际需求不匹配。
4. **项目位置错乱**：kelePro 整个项目（连同原静态版 kele）堆在 `demo/` 下，历史资料、示例项目、代码混在一起，需要收敛为单一 kele 项目。

## 2. 重构决策

| 决策项 | 结论 |
|--------|------|
| 项目归属 | 删除 `demo/kelePro`，在 kele 项目根目录重建唯一项目（前端 + 后端 + 文档） |
| 入口 | **微信小程序端 + 网页端（H5）**，uni-app 一套代码双端构建 |
| 部署 | Cloudflare 免费方案：Workers（API + 静态资源托管）+ D1 + KV，全部零成本 |
| 最高优先级需求 | **源扩展性**：提供新接口的配置即可接入，核心代码零改动、零部署 |
| 功能基线 | 以 kelePro 现有功能为基线裁剪（裁剪用户/VIP/广告体系，保留搜索全链路） |

### 非目标（本期不做）

- 用户注册登录、VIP 会员、支付、广告系统（留表结构扩展位，不实现）
- 网盘转存、在线播放
- 管理后台不做进小程序（仅 Web 端）

## 3. 用户与场景

| 用户 | 场景 |
|------|------|
| 普通访客 | 手机（小程序）/电脑（H5）搜索影视资料 → 按网盘筛选 → 复制链接+提取码 → 去网盘 App 保存 |
| 站长（唯一管理员） | 后台添加/停用搜索源、测试连通性、看健康度、发公告、管榜单 |

核心用户故事：

- **US-1**：访客搜索关键词，系统并行查询所有可用源，3 秒内返回按网盘类型分组的结果，失效链接有标记。
- **US-2**：某源失效后自动熔断（不影响整体搜索），后台健康度变红；站长粘贴新接口 URL + 字段映射，点"测试"，保存即生效——**不改代码不部署**。
- **US-3**：小程序用户复制资源时链接/提取码分步复制，符合小程序交互习惯。

## 4. 约束

### 4.1 Cloudflare 免费额度（设计红线）

| 资源 | 免费额度 | 设计约束 |
|------|----------|----------|
| Workers 请求 | 10 万/天 | 足够；基础限流防刷 |
| Workers CPU | **10ms/次** | HTML 解析爬虫必须轻量（kelePro 的 xiaozi/zhuiju 正则解析需精简） |
| Workers 子请求 | **50/次** | 单次搜索扇出源数 ≤ 10，失效抽检 ≤ 15 |
| D1 读/写 | 500 万行/天 / 10 万行/天 | 结果缓存走 D1；写入需批量+去重 |
| KV 写 | **1,000/天（最紧）** | KV 只存源健康度等低频状态；搜索缓存禁用 KV |
| Cron | 可用（免费） | 豆瓣全量、预热、清理、熔断探测 |

### 4.2 微信小程序（必须正视）

1. request 合法域名要求 **HTTPS + ICP 备案**，`*.workers.dev` 不可用 → 需自有备案域名绑定 Worker Custom Domain；无备案域名前小程序无法上线（H5 先行）。
2. 小程序内不能直接打开外部链接，交互以复制为主。
3. 内容合规：需免责声明页 + 后台"审核模式"开关（隐藏在线影视等敏感入口）。

## 5. 功能需求

优先级：P0 首版必须 / P1 尽量 / P2 二期。

### 5.1 搜索与结果

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| FR-01 | 关键词聚合搜索 | P0 | 并行扇出启用源（含 API 源与爬虫源），归一化合并去重 |
| FR-01a | **SSE 流式渐进推送** | P0 | 源返回即推送（先推后校验），失效校验流式更新；有效条目排前、失效自动沉底（客户端双桶）；REST `/api/search` 作兜底 |
| FR-02 | 网盘类型筛选 | P0 | 全部/夸克/阿里/百度/UC/迅雷/天翼；源无类型时按 URL 模式识别（沿用 cloud-detector） |
| FR-03 | 结果缓存 | P0 | 关键词结果 D1 缓存（默认 2h），缓存优先降低对源依赖 |
| FR-04 | 分页 | P0 | 首屏即返 + 触底加载 |
| FR-05 | 热搜关键词 | P1 | 搜索日志聚合 + 热门词预热 |
| FR-06 | 搜索历史 | P1 | 小程序/H5 本地存储 |

### 5.2 资源展示

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| FR-10 | 资源卡片 | P0 | 标题/网盘角标/来源/标签/失效状态/热度 |
| FR-11 | 复制链接与提取码 | P0 | 小程序分步复制；H5 一键复制 + 打开网盘 |

| FR-14 | 收藏 | P1 | 本地收藏（不依赖登录）；云端同步二期 |

### 5.3 内容

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| FR-20 | 公告 | P0 | 首页展示，后台维护 |
| FR-21 | 热播推荐 | P0 | 豆瓣榜单（剧集/电影/综艺），Cron 每日全量，点击即搜 |
| FR-22 | 在线影视导航 | P1 | kelePro 已有页面，保留，后台可配置 |

### 5.4 源管理（扩展性核心）

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| FR-30 | 源 CRUD | P0 | 名称/URL/方法/请求头/请求体/解析器/优先级/启停（api_configs 升级） |
| FR-31 | **声明式接入（L0）** | P0 | 后台表单配置结果数组 JSON 路径 + 字段映射，保存即生效，零代码零部署 |
| FR-32 | 测试连通 | P0 | 输入测试词实测源，显示原始响应与解析结果对比 |
| FR-33 | 内置解析器库（L1） | P0 | 原版 searchApi1/2/3/4 + kelePro 的 lzpan/xiaozi/zhuiju 全部内置 |
| FR-34 | 爬虫适配器（L2） | P1 | HTML 源独立适配器，注册即用 |
| FR-35 | 健康度 + 熔断 | P0 | 成功率/耗时/连续失败 → 自动熔断 → Cron 定期探测恢复 |
| FR-36 | 管理员认证 | P0 | 单管理员账号 JWT（替代 kelePro 的用户注册体系） |

### 5.5 非功能

| 类别 | 需求 |
|------|------|
| 性能 | 搜索 P95 ≤ 3s（单源超时 3s 熔断）；缓存命中 P95 ≤ 500ms |
| 可用性 | 任一源失效不影响返回；全部失效时读缓存并提示 |
| 安全 | 管理 JWT；每 IP 20 次/分钟限流；修复 kelePro `/api/debug/*` 无鉴权问题；CORS 白名单 |
| 合规 | 不存储资源；声明页；侵权邮箱 |
| 扩展性 | 三级接入：L0 声明式配置（0 代码）→ L1 解析器（1 文件）→ L2 爬虫适配器（1 文件+注册） |

## 6. 页面需求

### 小程序端（TabBar 四页）

```
├── 首页      公告 + 搜索框 + 热搜词 + 热播推荐(剧集/电影/综艺)
├── 搜索结果   类型多选 chips + 结果卡片 + 分页 + 报失效
├── 在线影视   站点导航（审核模式下可隐藏）
└── 我的      搜索历史 + 收藏(本地) + 免责声明
详情页        资源完整信息 + 复制区（非 tab 页）
```

### 网页端（H5 响应式）

```
├── 首页      标题/暗亮切换/公告/搜索/筛选/热播榜/在线影视
├── 搜索结果   PC 单选、移动多选
├── 详情页    （可选）
├── 声明页    /about
└── /admin    管理后台（仅桌面 Web）：源管理/健康度/公告/导航/概览
```
