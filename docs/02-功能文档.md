## A.4 搜索核心流程（[services/search.ts](file:///e:/HelloWorld/project/kele/demo/kelePro/worker/src/services/search.ts)）

```
请求 → D1 缓存命中（新鲜结果）→ 直接返回
  ↓ 未命中
并行调用多源爬虫（crawlers/index.ts 注册表）
  ├── lzpan.ts   通用 API 源：从 D1 api_configs 表读配置发请求（已有配置化雏形）
  ├── xiaozi.ts  盘小子：HTML SSR 数据块正则解析（前2页）
  └── zhuiju.ts  追剧吧：搜索页内嵌 JSON/链接提取
  ↓
归一化 → 按链接去重 → 写 resources 表 → 校验有效性 → 异步补爬剩余页
```

## A.5 定时任务（[schedules/](file:///e:/HelloWorld/project/kele/demo/kelePro/worker/src/schedules) + wrangler crons）

| Cron | 任务 | 说明 |
|------|------|------|
| `0 0 * * *` | douban | 豆瓣 rexxar API 全量拉取热播剧集/电影/综艺 → 清旧写新 douban_items |
| `30 0 * * *` | prefetch | 取豆瓣热播标题 → 多源搜索 → 写 resources（预热）+ 有效性校验 |
| `30 12 * * *` | prefetch | 同上（午后预热） |
| `0 3 * * *` | cleanup | 清理过期缓存（资源 5 天过期） |
| `0 5 * * *` | aggregate | 聚合搜索日志 → 热搜关键词 |

## A.6 数据库（D1，[db/schema.ts](file:///e:/HelloWorld/project/kele/demo/kelePro/worker/src/db/schema.ts)）

核心表：`users`（含 vip_level/vip_expire_at/search_count）、`resources`（title/url 唯一/cloud_type/is_valid/source/keyword/heat/expire_at）、`resource_tags`、`user_favorites`、`api_configs`（name/url/method/request_type 解析器标识/headers/status/priority）、`cloud_types`（含 url_pattern）、`notices`、`ad_configs`、另有 ads/api_logs/search_logs/cron_tasks/douban_items/hot_keywords 等模块对应表。

# B. 第三方数据源与接口契约

> 契约文档存于 [apidoc/](file:///e:/HelloWorld/project/kele/demo/kelePro/Docs/示例项目/kele/apidoc)（原静态版留档）。这些是"易失效"问题主体。

## B.1 搜索源

| 解析器 | 源 | 请求 | 返回特征 |
|--------|-----|------|----------|
| searchApi1 | iyuns `GET https://api.iyuns.com/api/wpysso?kw=&cloud_types=` | GET，无认证 | `data.merged_by_type.{quark,aliyun,baidu}` 按网盘分组 |
| searchApi2 | eeeob / dbpan 系列 `POST /v/api/search|getJuzi|getDyfx`（name+token） | POST 表单 | `answer` **纯文本**，正则抽"链接：/提取码：" |
| searchApi3 | duoduopuzi `POST /mv/api/movies/search` | POST | 结构化 JSON 列表 |
| searchApi4 | duoduopuzi `POST /mv/api/crawler/search` | POST | 爬虫聚合 JSON |
| HTML 爬虫 | 盘小子 xiaozi / 追剧吧 zhuiju（kelePro 新增） | GET 页面 | SSR HTML 块正则/内嵌 JSON 解析 |

共性风险：个人域名随时停服；HTTP 明文；返回结构无版本承诺；文本型解析对格式变化零容忍。

## B.2 失效检测契约

| 网盘 | 端点 | 失效判定 |
|------|------|----------|
| 夸克 | `POST https://drive-h.quark.cn/1/clouddrive/share/sharepage/token`（body: pwd_id/passcode） | `code=41012` 等 410xx 错误码 |
| 阿里 | `POST https://api.aliyundrive.com/adrive/v3/share_link/get_share_by_anonymous`（share_id） | `NotFound.ShareLink.*` 错误码 |
| 百度 | `GET {分享链接}` 读 HTML | 含"百度网盘-链接不存在" |

UC/迅雷/天翼：无检测器（unknown 态）。原版浏览器端检测需经腾讯云函数代理网关（`X-App-Id` 鉴权）；kelePro 已改为 Worker 服务端直连（正确方向，保留）。

## B.3 榜单源

- 豆瓣 rexxar API（kelePro douban.ts）：按剧集/电影/综艺分类拉取，分类结构 `剧集(综合/近期热度/高分优先/热门)`、`电影(热门/高分/最新)`、`综艺`。
- 原静态版备用：`GET https://xzdx.top/api/tophub/{tv|movie}`（tophub 镜像，searchApi99）。

## C.3 统一资源模型

```ts
interface Resource {
  title: string;            // 标题
  url: string;              // 分享链接（去重主键）
  cloud_type: 'quark'|'aliyun'|'baidu'|'uc'|'xunlei'|'tianyi'|'other';
  passcode?: string;        // 提取码
  note?: string;            // 描述
  tags?: string[];          // 4K/中字/全集
  cover?: string;           // 封面（可空）
  published_at?: string;    // 发布时间（可空）
  source_id: string;        // 来源
  validity: 'unknown'|'valid'|'invalid';
}
```

## C.4 管理后台规格

1. **概览**：今日搜索量、缓存命中率、各源调用量与成功率、熔断状态。
2. **源管理**：表格（名称/类型/解析器/优先级/启停/健康度）；新增/编辑表单：
   - 请求：URL 模板（`{kw}`/`{page}` 占位）、方法、请求头 JSON、请求体模板 JSON、超时 ms。
   - 解析：下拉选内置解析器（searchApi1/2/3/4/lzpan/xiaozi/zhuiju…）**或**声明式映射。
   - 声明式映射：结果数组路径（支持多路径，如 `data.merged_by_type.quark` 固定 cloud_type=quark）、字段映射（title/url/passcode/cloud_type → JSON 路径或常量）。
   - 保存前强制"测试连通"。
3. **健康度**：每源近 24h 成功率、平均耗时、连续失败数、熔断状态；一键重测/恢复/禁用。
4. **公告/导航**：增删改、启停、排序。
5. **审核模式**：总开关，隐藏在线影视与部分入口（小程序提审用）。
6. **兜底**："仅缓存模式"开关（全部源失效时只读缓存）。
